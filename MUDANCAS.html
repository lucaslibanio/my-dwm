Seu DWM, revisado

O que mudou em ~/.source, como instalar e todos os atalhos novos. A maior mudança: a tecla principal agora é Super (a tecla Windows), não mais Alt.

1. Instalar

As mudanças já estão nos arquivos e commitadas no git, mas ainda não foram instaladas no sistema.

  1. Compile e instale os três programas: 
    cd ~/.source/my-dwm    && sudo make clean install
cd ~/.source/dwmblocks && sudo make clean install
cd ~/.source/dmenu     && sudo make clean install
  2. Reinicie o dwm com o atalho antigo, porque o dwm em execução ainda usa Alt: Alt+Ctrl+Shift+Q. As janelas abertas são mantidas.
  3. Reinicie a barra de status: 
    pkill dwmblocks; setsid -f dwmblocks
  4. A partir daqui, use Super para tudo. Para reiniciar no futuro: Super+Ctrl+Shift+Q.
Para desfazer: cada repositório tem as mudanças em commits próprios. Use git log para vê-las e git revert HEAD (ou git checkout <commit> -- config.h) para voltar atrás. Depois, recompile.

3. Barra de status clicável

Agora o dwm repassa os cliques na barra de status para o dwmblocks (patch statuscmd). Cada bloco é um script em ~/.source/dwmblocks/scripts/ que recebe o botão do mouse na variável $BLOCK_BUTTON.

Rolar o mouse sobre o símbolo do layout ([]=) também troca de layout.

4. O que mudou

my-dwm · config.h

Aparência

  • Borda de 2px com destaque #d79921 na janela em foco (antes era 0px, sem indicação de foco).
  • Espaçamentos uniformes de 10 em todos os lados (antes eram 20/10/10/30).
  • resizehints = 0: o st não deixa mais faixas vazias nas bordas.
  • Fonte corrigida para o nome do fontconfig (Ubuntu Mono:style=Italic), com Symbols Nerd Font como fallback para ícones.

Comportamento

  • MODKEY = Super. Acabam os conflitos com Alt+b/d/f do terminal e do navegador. Os espaçamentos foram para Super+Alt.
  • dmenu abre no monitor atual e com as mesmas cores da barra, que seguem o Xresources ao apertar Super+F5.
  • Regras: só a do Gimp (flutuante). Os navegadores abrem na tag atual. A regra do Dunst foi removida, porque não fazia nada.

5. Para conferir e fazer à mão

  • Pacotes que os atalhos e scripts novos usam: 
    sudo pacman -S --needed playerctl libpulse pavucontrol libnotify ttf-nerd-fonts-symbols
    libpulse fornece o pactl, que também funciona com o PipeWire.
  • Data em português: precisa do locale pt_BR.UTF-8. Descomente a linha dele em /etc/locale.gen e rode sudo locale-gen. Sem isso, a data aparece em inglês, mas já em 24h.
  • Fonte: confira o nome exato com fc-list | grep -i ubuntumono. Se o estilo não for Italic, ajuste em config.h no dwm e no dmenu.
  • Bloquear ao suspender: adicione ao ~/.xinitrc, antes do exec dwm: 
    xss-lock -- slock &
    Isso não foi alterado, porque o arquivo fica fora de ~/.source.
  • Super+P em notebooks Lenovo: a tecla Fn de trocar de tela pode mandar exatamente Super+P, o que abriria o dmenu. Se isso incomodar, troque o atalho do dmenu para XK_d e mova o incnmaster −1 para outra tecla.
  • Gerenciador de arquivos: Super+E roda xdg-open ~, que abre o gerenciador padrão do sistema. Para usar outro, troque FILEMGRCMD no config.h.
